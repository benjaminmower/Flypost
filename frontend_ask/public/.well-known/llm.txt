# Flypost Ask - Discovery Protocol Read Surface

service_name: Flypost Ask
service_purpose: >
  Flypost Ask is the read-only discovery surface for the Flypost Discovery
  Protocol. Agents use it to discover local events by place and time.

  Canonical API contract:
  https://api.goflypost.com/.well-known/openapi.yaml

  Canonical protocol doc:
  docs/flypost-discovery-protocol.md

base_url: https://api.goflypost.com
canonical_openapi: https://api.goflypost.com/.well-known/openapi.yaml

## Core Endpoints

### GET /v1/events/near

Retrieve local events near a latitude/longitude.

Results are:

- filtered by requested radius
- limited to events with coordinates
- sorted nearest-first
- returned as Discovery Protocol V1
- annotated with distance_mi when available

Use `radius_mi=1.25` for a hyperlocal 90405-style query.

### GET /v1/events/{event_id}

Retrieve one event by ID. Response uses the same Discovery Protocol V1 envelope
with an events array containing one item.

## DiscoveryEventV1

Registry-safe event projection:

- eventId
- dataHash
- what: type, label
- where: latitude, longitude, address
- when: start, end, timezone
- externalListingUrl
- shareUrl
- imageUrl
- distance_mi on near-query responses
- source

Public anonymous responses may use reduced coordinate precision. `distance_mi`
is computed from full-precision source coordinates before public rounding.

## Categories

open_house, garage_sale, estate_sale, moving_sale, yard_sale, apartment,
job_posting, live_event, community_alert, happy_hour, missing_pet, other.

## Rules For Agents

1. Use the API; do not invent event data.
2. Preserve `/v1/events/near` order unless the user asks for another sort.
3. Display `distance_mi` when present.
4. Use `shareUrl` as the public handoff URL.
5. Do not publish through this read surface. Use authenticated write endpoints
   on `https://api.goflypost.com` or the PWA post flow.

## Publishing

Publishing is separate from read-only discovery:

- `POST /api/parse-and-publish` with Firebase bearer auth or write token
- `POST /v1/events/upsert` with write token

Human PWA posting:

```text
https://app.goflypost.com/post
```
